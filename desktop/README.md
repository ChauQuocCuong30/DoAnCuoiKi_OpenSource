# Desktop — dự phòng
Chưa có Electron hoặc bộ cài. Chỉ triển khai sau khi web/API hoạt động ổn định.
Mã chính đặt ở src/, tài nguyên ở resources/. Không đóng gói .env backend hoặc thông tin MySQL.
Nếu chọn Electron, thêm package.json và lockfile trong desktop/ qua PR được duyệt.
Không commit node_modules, dist hay bộ cài. Bổ sung quy trình cập nhật và lưu thông tin xác thực an toàn khi triển khai.
